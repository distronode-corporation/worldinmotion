# Getting help

worldinmotion is a small open-source project with no paid support. Help comes through this
repository.

- **A bug** in `wim`, a relay, the Claude Code plugin or the VS Code extension: open an
  [issue](https://github.com/distronode-corporation/worldinmotion/issues) with what you ran, what
  happened and what you expected, plus your Node version and OS. Never paste a device key file,
  an invite code or an operator key.
- **A security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **Abuse on the hosted relay** (`wss://worldinmotion.distronode.com`): email
  **opensource@distronode.com**; see [docs/hosted-relay.md](docs/hosted-relay.md).
- **Anything else** that is not a bug: email **opensource@distronode.com**.

Only the latest release is supported. Before reporting, check that you are on it (`wim --version`)
and run `wim doctor`, which checks the setup and shows what the relay says about itself.
